# Vahid AI Android

این پروژه اندرویدی مستقل در پوشه `android-app` قرار دارد تا فایل‌های برنامه وب اصلی دست‌نخورده بمانند.

## ساخت APK
گردش‌کار GitHub Actions پس از push یا با اجرای دستی، APK آزمایشی را می‌سازد و به‌صورت Artifact با نام `Vahid-AI-debug-APK` منتشر می‌کند.

## وضعیت عملکرد
رابط برنامه شامل بخش‌های بازار، تحلیل نمودار، سیگنال، نهنگ‌ها، Order Flow، نقدینگی مهندسی‌شده و جاروی نقدینگی است. تا زمانی که سرویس داده و کلیدهای API معتبر متصل نشده‌اند، برنامه نباید قیمت، جریان سفارش یا سیگنال ساختگی نشان دهد و در این حالت `INSUFFICIENT DATA` نمایش می‌دهد.

این خروجی APK آزمایشی (debug) است، نه نسخه امضاشده برای انتشار فروشگاهی.
