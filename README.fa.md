# Vahid AI

نسخه آغازین مستقل برای داشبورد هوشمندی بازار؛ هیچ فایل یا سرویس پروژه‌های WAL و IranStockAI را تغییر نمی‌دهد.

## اجرای محلی
نیازمند Node.js نسخه 20 یا جدیدتر:
```bash
npm start
```
سپس `http://localhost:3000` را باز کنید.

## API
- `GET /api/status` وضعیت سرور
- `GET /api/crypto` قیمت رمزارزها از CoinGecko API با کش ۲۰ ثانیه‌ای؛ در صورت خطای منبع، وضعیت OFFLINE و قیمت null برمی‌گردد.
- `GET /api/analysis` وضعیت اتصال ماژول‌های تحلیلی

## استقرار در Render
مخزن را به‌عنوان یک **Web Service مستقل** متصل کنید. Build command: `npm install` و Start command: `npm start`. فایل `render.yaml` برای Blueprint نیز موجود است. پس از استقرار، `/api/status` را بررسی کنید.

## محدودیت‌های شفاف
این نسخه هنوز دفتر سفارشات/تیک‌دیتا برای Order Flow، داده آن‌چین برای ردیابی نهنگ‌ها، قیمت زنده طلا/نقره/فارکس، اعلان‌ها، احراز هویت، پایگاه داده یا اجرای معامله خودکار ندارد. هیچ‌کدام نباید زنده یا تکمیل‌شده معرفی شوند تا منبع معتبر متصل و تست نشده باشد. رابط کاربری تا زمان اتصال، داده ساختگی یا سیگنال معامله نمی‌سازد.

CoinGecko API عمومی ممکن است محدودیت نرخ درخواست داشته باشد و دسترس‌پذیری آن تضمین‌شده نیست.
